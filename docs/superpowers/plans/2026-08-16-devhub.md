# DevHub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a shell-integrated DevHub app that reproduces xDele1ed's GitHub profile as a responsive GitHub Dark portfolio with working tabs, filters, contribution activity, API fallback, and secure project redirects.

**Architecture:** A standalone CommonJS/browser module constructs one DevHub window before the existing Windows 7 engine inventories apps. Immutable configuration and pure filtering/heatmap helpers remain separately testable, while `DevHubApp` owns DOM state and injected browser/network boundaries. A namespaced stylesheet owns the GitHub Dark document surface; the existing shell continues to own window chrome and lifecycle.

**Tech Stack:** Vanilla JavaScript, semantic HTML generated through DOM APIs, CSS, Node.js built-in test runner, existing Windows 7 shell and 7.css.

```javascript
(function initializeDevHub(globalScope, factory) {
  const api = factory(globalScope);
  if (typeof module === "object" && module.exports) module.exports = api;
  if (globalScope) globalScope.Windows7DevHub = api;
})(typeof window === "object" ? window : globalThis, (globalScope) => {
  "use strict";

  const filterRepositories = (repositories, query = "", language = "all") => {
    const needle = String(query).trim().toLocaleLowerCase();
    return repositories.filter((repository) => {
      const languageMatches = language === "all" || repository.language === language;
      const haystack = [repository.name, repository.description, repository.language, repository.badge]
        .join(" ")
        .toLocaleLowerCase();
      return languageMatches && (!needle || haystack.includes(needle));
    });
  };
```
